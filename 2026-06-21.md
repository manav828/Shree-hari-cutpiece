## 2. Theme Leak Fix — Classic Product Page Showing Bohemian Navbar
**Root Cause:** `getActiveTheme()` checks cookie before DB. If a stale `storefront_theme` cookie said "bohemian" (from admin preview), the server returned "bohemian" and the inline sync script compared cookie against the same cookie-prioritized value — they always matched, so stale cookies never got corrected.

**Changes:**
- `src/lib/theme.ts` — Added `getDbActiveTheme()` that fetches DB theme without cookie priority
- `src/app/layout.tsx` — Inline script now compares cookie against DB theme (not cookie-prioritized). If mismatched, corrects cookie and reloads
- `src/themes/classic/core/components/shop/ProductDetailClient.tsx` — Changed `CartSidebar` import from theme-aware wrapper to direct classic theme import
- `tsconfig.json` — Removed bohemian-first priority from `@/*` catch-all path

## 3. Classic Shop Page Filter Fix
- `src/themes/classic/core/components/shop/ProductGrid.tsx` — Removed sticky positioning from filter bar; replaced category buttons with searchable `<select>` dropdown (desktop + mobile)

## 4. Admin CMS — Theme-Aware Landing Page Sections
**Problem:** CMS Landing Page Sections were hardcoded to bohemian theme (all keys `bohemian_*`). Classic theme had no way to manage its content.

**Changes to `src/app/admin/cms/page.tsx`:**
- Added "Managing:" theme dropdown (Classic/Bohemian/Luxury) in the sections tab header
- Added `themeKey(suffix)` helper — returns unprefixed keys for classic (`hero_badge`), prefixed for others (`bohemian_hero_badge`)
- Added `themeValue(suffix, fallback)` helper for reading values
- Added `handleThemeChange()` to reload theme-specific state on dropdown switch
- All 5 section editors (Hero, Archive, Spaces, Journal, Harvested) now use theme-prefixed keys
- Section cards show live preview of actual content values from the selected theme
- Added "Why Choose Us" (description) section editor for classic with 13 fields
- Added "Shop by Category + Fabric Categories" editor with 3 category dropdowns
- Added "Premium Collection" editor with auto/manual mode + product checkbox picker
- Added "Best Sellers" editor with auto/manual mode + product checkbox picker
- Added "Fabric Guides for Smarter Buying" editor with auto/manual mode + blog checkbox picker
- Added "Follow Us" editor with Instagram reels CRUD (add/edit/remove reels with title, thumbnail, URL)

# 10 — AI Skills & Tools Reference

The best Antigravity skills to use for this project. Mention them in your prompt to activate.

> Source: `RECOMMENDED_SKILLS.md`

---

## Framework & Language

| Skill | When to Use |
|-------|-------------|
| `react-nextjs-development` | Building App Router pages, Server Components, data fetching |
| `nextjs-app-router-patterns` | Advanced Next.js 14+ patterns, streaming, parallel routes |
| `react-best-practices` | React performance optimization, hooks best practices |
| `react-patterns` | Component composition, TypeScript patterns |
| `typescript-advanced-types` | Complex type safety, generics, type guards |

## UI, Styling & Design

| Skill | When to Use |
|-------|-------------|
| `tailwind-patterns` | Tailwind CSS v4, container queries, design tokens |
| `frontend-design` | Building premium, production-grade UI |
| `ui-ux-pro-max` | Planning new e-commerce sections, brainstorming UI |
| `scroll-experience` | Parallax, scroll-driven animations, immersive experiences |

## Performance & Quality

| Skill | When to Use |
|-------|-------------|
| `web-performance-optimization` | Core Web Vitals, bundle size, caching |
| `clean-code` | Reviewing and refactoring components |
| `frontend-dev-guidelines` | React + TypeScript standards |

## SEO & E-commerce

| Skill | When to Use |
|-------|-------------|
| `seo-audit` + `seo-fundamentals` | Product/blog pages SEO optimization |
| `page-cro` | Conversion rate optimization |

## Design Generation (Stitch MCP)

| Tool | When to Use |
|------|-------------|
| `StitchMCP` | Generate new theme screens — use with `09-THEME-AND-STITCH-RULES.md` |

Just mention it in your prompt:
> "Review my `FeaturedProducts.tsx` using the **react-nextjs-development** and **clean-code** skills"

# Product Setup Example: Cotton Printed Kurti Fabric (Sold by Meter)

Use this as a template when creating new products with options, description HTML/CSS, and SEO.
This example uses all option types without price add-ons.

---

## 1) Product Basics

- Name: Cotton Printed Kurti Fabric
- Slug: cotton-printed-kurti-fabric
- Category: Kurtis / Dress Material
- Short description: Soft cotton fabric with block prints, ideal for daily wear kurtis.
- Sell mode: meter
- Fabric/care: Cotton; gentle wash, dry in shade

---

## 2) Variants

Create at least one variant and mark a default.

- Variant A
  - Color: Indigo Blue

  - Images: 3 images, 1 primary

- Variant B

  - Price: 220

---

## 3) Product Options (All Types)

Option Group 1: Finish
- Type: radio
- Required: yes
- Values: Matte (default), Glossy

Option Group 2: Pack Size
- Type: dropdown
- Required: yes
- Values: Single (1 meter), Double (2 meters)

Option Group 3: Included Accessories
- Type: multi-select
- Required: no
- Min selections: 0
- Max selections: 2
- Values: Matching buttons, Matching lace, Extra thread

Option Group 4: Custom Stitch Note
- Type: input (text)
- Required: no
- Placeholder: "Leave a note for cutting/stitching"
- Min length: 3
- Max length: 40

Notes:
- Options here do not change price.
- Use required only when the order cannot be processed without that choice.
